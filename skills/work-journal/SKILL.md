# work-journal

業務の振り返り（`recap`）と終了時のジャーナル記録（`save`）。保存先・ローテーション・スケジュールは外部運用。外部の記憶ストアには保存しない。

## モード

| 指示 | モード |
|------|--------|
| recap / 「何やってたっけ」 / 週末・週明けの振り返り | `recap` |
| save / ジャーナルを保存 / 作業を記録 | `save` |

未指定なら確認。「振り返って保存」など両方なら `recap` → `save`。「終わり」だけでは起動しない。

## 入力ソース（優先順）

1. ローカルに残るエージェントセッション記録（全文）。日時は user メッセージ内の時刻表示を根拠にする。
2. 利用可能な会話検索（タイトル・短い抜粋）。無ければ「取得不可」。
3. 明示されたジャーナル保存先があるときだけ、その既存ログ（突き合わせ）。
4. **外部補助（任意）** — コードホスト / チャット / wiki・ドキュメント。接続・権限があり、ユーザーが対象を示したとき、またはクライアントから期間照会できるときだけ。手順・ツール名・社内 URL はこの skill に書かない。詳細は [reference.md](reference.md)。

区画導出・記録の読み方は [reference.md](reference.md)。

### プロジェクト範囲

| 指定 | 範囲 |
|------|------|
| パス・セッション記録の場所・区画（`~/…`）あり | その範囲だけ |
| なし | ローカルのセッション記録を期間で見回り、実行時の `~` ツリーから導出した区画ごとにまとめる |
| 外部のリポ・チャンネル・スペース等の指定あり | セッション範囲に加え、その対象だけ外部補助を読む |

区画名や識別子の具体値は skill に固定しない。導出は [reference.md](reference.md)。取得できない記録は推測せず「取得不可」。

## 機密・個人情報

recap の出力にも save の記録にも、次を**入れない**（ユーザーが明示的に含めるよう求めたときだけ例外）:

- 顧客名・案件の背景・契約や社内コード
- 担当者・連絡先・個人を特定できる情報
- 期限・金額・評価・未公開の計画
- 秘密値・認証情報・長文の原文引用

要約は作業の種類と結果に留め、固有名詞は一般化する。

## recap（読み取り専用）

1. **期間** — ユーザー指定を優先。なければ直近の金曜 18:00 JST 〜 現在。推定範囲を冒頭に書く。
2. **収集** — 範囲内のセッション記録と、利用可能なら会話検索を期間で絞る。時刻のない行は日付判定に使わず識別子・並びだけで扱う。
3. **外部補助** — 接続があるときだけ。ユーザー指定のリポ／チャンネル／スペース等を優先。指定なしで期間照会できるなら最小限。できない・拒否されたら「取得不可」で続行（失敗にしない）。長文・スレッド全文は要約のみ。
4. **区画** — 各ヒットを `~` 起点の区画に振り分ける。制御 checkout と隔離 worktree は同一区画に寄せ、同一セッション識別子は重複排除（全文があれば全文優先）。外部だけの根拠は区画推定できなければ `other`。
5. **突合** — 会話検索の識別子で全文記録があれば全文優先。無ければ「概要のみ」。外部補助はセッション要約の裏付け・穴埋めに使い、セッションと矛盾するときは両方書いて推測結合しない。
6. **抽出** — 依頼の種類、変更の概要、検証の有無、未完了・エラー終了、次の指示。事実と推測を分離。上記の機密・個人情報ルールを適用。
7. **保存突き合わせ** — 保存先があるときだけ、ログにセッション識別子が無いものを「未保存」。無いときは保存状態を推測しない。
8. **出力**（必須順）:
   - 期間と調査範囲（見回った区画・外部対象の一覧）
   - ソース別の取得可否（ローカル / 会話検索 / ジャーナル / 外部種別ごと）
   - **区画ごとの**時系列の作業要約（外部だけの項目は出典を明記）
   - 未完了・ブロッカー（区画付き）
   - 次にやること（優先順位付き・区画付き）
   - 根拠（日時・識別子・区画・外部があれば種別と参照名のみ）
9. **失敗** — 記録なし・期間不明・途中終了は補完せず制約を明記。外部だけの欠落は全体失敗にしない。

ファイルは作らない・変更しない。外部サービスへは書かない。

## save

1. **対象** — 当該セッション全体を 1 ブロック。日跨ぎなら見出しに日付範囲を書く。
2. **識別子** — 現在のセッション記録上の ID。不明なら `session:unknown` でブロックだけ出し、**追記しない**（冪等不能）。
3. **ブロック** — 下のテンプレート。機密・個人情報ルールを守る。未確認は「未確認」。
4. **保存先** — ユーザーまたはスケジュールが明示した絶対パスがあるときだけ末尾追記。環境変数を勝手に読まない。既存内容は変更しない。
5. **冪等** — キー `session:<id>`。既にあれば追記せず「既存」。
6. **未指定** — パスを推測・作成せず、ブロックだけ出力して「未保存」。

```markdown
## HH:MM-HH:MM <短いタイトル> (session:<id>)
- 依頼:
- 実施:
- 検証:
- 未完了/ブロッカー:
- 次:
- 成果物: <種別のみ。なければ「なし」>
```

## 禁止

- この skills 正本リポジトリ配下へのジャーナル作成
- 保存先未指定時のパス推測・`logs/` の新規作成
- 外部の記憶ストアやサービスへの保存（外部は入力のみ）
- 外部 API・社内 URL・接続手順のこの skill への固定記載
- 通常の個別作業での自動スキャン・自動保存
